# Preparar o repositório

Nome sugerido: estoque-em-foco
Descrição: React and TypeScript stock filtering demo with composable filters, derived metrics and keyboard navigation.
Topics: react typescript frontend inventory filters playwright accessibility portfolio

Crie um repositório vazio e revise a visibilidade desejada. Na pasta extraída, rode:

```bash
git init
git add .
git commit -m "feat: add stock filtering demo with tested business rules"
git branch -M main
```

Adicione o endereço do seu próprio repositório com `git remote add origin URL` e faça `git push -u origin main`. Não envie node_modules, dist, arquivos .env ou test-results. Revise o resultado do workflow em Actions. Ele foi preparado e não foi executado no GitHub nesta entrega.

Anexe o MP4 ao post do LinkedIn e revise docs/LINKEDIN.md. Não publique credenciais ou dados de clientes. Este pacote usa apenas dados fictícios.
